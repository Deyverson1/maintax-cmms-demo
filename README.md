# MaintaX CMMS

Sistema de Gestión de Mantenimiento Industrial (CMMS) enfocado en apoyar la planificación, ejecución y control de actividades de mantenimiento en entornos industriales.

## 🚀 Tecnologías

- React + Vite
- Tailwind CSS
- Librerías 

## 🤖 Automatizaciones (planeado)

El sistema contará con una capa de automatización para:

- Envío de alertas
- Generación de reportes automáticos
- Integraciones con otros servicios
- Procesamiento de documentos

Estas automatizaciones se implementarán mediante herramientas como n8n y webhooks.

## 📌 Estado del proyecto

En desarrollo.

## 🎯 Objetivo

Construir una plataforma web que permita:

- Gestión de equipos
- Programación de mantenimientos
- Registro de actividades
- Reportes y estadísticas
